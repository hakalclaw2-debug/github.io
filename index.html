Privacy policy

HSA Tracker is a private tool used only by the members of one household. It is not available to anyone else.

  • Google Drive: it accesses only files and folders it created itself (scope drive.file).
  • Gmail: it reads and labels messages only in a dedicated intake mailbox owned by the household.
  • Document text is sent to the Anthropic API solely to extract receipt data. No data is sold, shared for advertising, or used for any other purpose.
  • Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.
  • Data is stored on a private server and in the owner's Google Drive. Access can be revoked at any time at myaccount.google.com/permissions.
